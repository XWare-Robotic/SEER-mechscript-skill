# 接口查询

从仙工《机构脚本接口字典》第 2 节查接口、返回类型和支持版本，再读第 3 节对应条目。对照仙工《机构脚本使用通识介绍》第 2、5 节及仙工 SDK 包 `syspy.zip` 中的 `rbk.py`、`rbkSim.py` 与调用示例。以下差异在 2026-11-13 核对，通识修订 826，字典修订 7868；换 SDK 或目标版本时重查相关条目与源码。向厂商或项目维护者取得对应版本的资料。公开入口见[仙工智能帮助中心](https://seer-robotics.ai/zh/help-center)。

对正在改动的每个接口，记下目标 RoboKit/Python 版本、输入类型、单位和坐标系、返回值、完成信号及出处。字典未收录时可用 `rbkSim.py` 查名称和签名；仅有模拟实现时将控制器支持标为待核实。优先用目标版厂商文档、控制器现有版本记录和既有运行证据收敛差异。

## 常用接口与差异

| 用途 | 仙工字典修订 7868 | 本地 SDK 与核对点 |
| --- | --- | --- |
| 路径设置 | `setPathOnWorld(x, y, angle)`：世界坐标系，无返回值，版本栏为 3.3.5.80 起。 | `goPath.py` 用米和弧度，另有车体系 `setPathOnRobot`。字典的 `setPathOnWorld` 条目未明确 `angle` 单位，待目标版核实。 |
| 路径推进与完成 | `resetPath()`、`goPath()` 无返回值；`isPathReached()` 返回 `bool`；版本栏均为 3.3.5.80 起。 | 模拟 `goPath()` 和 `isPathReached()` 都直接返回 `True`。包内 `goPath.py` 用 `goPath(self.param)`，与本包模拟签名及字典无参示例不同；带参支持待目标版确认。 |
| 电机命令与到位 | `setMotorPosition(motor_name, pos, maxVel, stopDI)` 和 `isMotorPositionReached(motor_name, pos, stopDI)` 返回 `bool`，版本栏均为 3.3.5.80 起。 | 位置可能是直线量或角度；`maxVel` 受电机模型限制。按目标电机模型核对单位、范围、容差及 `stopDI` 配置和触发语义。模拟两者直接返回 `True`，未检查实际运动。 |
| 状态与日志 | `moveTask()`、`Di()`、`loc()` 返回字典；`setInfo(ss)` 和 `setError(ss)` 无返回值。 | 先确认实际字段、类型和新鲜度。通识第 6 节说明 `setInfo` 上报至 `move_status_info`，`logInfo` 写 RoboKit 日志。调用日志接口与返回作业状态分开验证。 |
| 停止 | `stopRobot(flag)` 无返回值，版本栏为 3.3.5.81 起。字典区分 `True` 与按 `StopAcc` 减速的 `False`。 | 用目标版与车型资料核实停止语义。返回值和调用日志不能证明底盘停稳，也不能证明安全回路已动作。 |
| 货物模型 | `forkGoods(load, recfile)` 无返回值；`setLocalShelfArea(object_model_path)` 返回 `bool`，`resetLocalShelfArea()` 无返回值。版本栏均为 3.3.5.80 起。 | 模拟 `forkGoods` 固定返回 `4`，另两个固定返回 `True`。要确认目标版模型是否生效，另查相应状态或控制器证据。 |
| 版本 | `robokitVersion()` 返回字符串；字典版本栏写 3.3.5.80 起，说明和示例出现 3.3.5.11。 | 模拟固定返回 `"3.3.5.11"`。实际控制器版本与接口最早支持版本均不能由模拟值推断。 |

路径的速度和精度还要核对各自的接口。SDK 的 `rbkSim.py` 将 `setPathMaxSpeed`、`setPathMaxRot`、`setPathReachDist`、`setPathReachAngle` 分别注释为 m/s、rad/s、m、rad；`setPathHoldDir` 是度。不要用一个统一的角度单位覆盖所有接口。

## 返回状态

通识第 2.3 节要求 `run` 返回 `MoveStatus`。包内枚举还定义了 `NEARTOGOAL`，通识列出的常用脚本状态未包含它；未经目标版核对，不把它当成自定义作业的终态。包内 `BasicModule.run` 和 `setShelf.py` 返回 `.value`，`waitDI.py` 返回枚举。维护时保留已知能用的形式，迁移时验证控制器接受的形式。日志接口的返回值、模拟器返回值和 `run` 的作业状态各有不同含义。

## 通用旋转脚本的适用范围

涉及底盘独立旋转、托盘旋转或随动、顶升及其组合时，按需查仙工示例的「试用范围」「支持功能」「模型文件配置要求」和「脚本参数说明」。托盘旋转使用 `spin` 电机，顶升使用模型里的第一个 `linear` 电机。底盘和托盘的目标角分别以世界坐标系和机器人坐标系为基准。启用前按目标车型和 RoboKit 版本核对机构、模型和版本要求。见[《通用旋转脚本使用说明》](https://seer-group.feishu.cn/wiki/UHG6whdg3iduphkrjXXc3kMcnPf)（修订 977）。

这些托盘旋转和升降示例适合作为顶升式 AGV 的参考。叉车门架、货叉和外部执行器应按本车的模型配置及机构接口契约实现。只有车型、机构和模型配置都匹配时，才考虑复用相应的示例功能。
