# 模拟与回放

## 本地检查

1. 先记下目标解释器版本。在临时目录用 `python -m py_compile` 检查脚本副本及其 Python 依赖文件。单独解析 `DEFAULT ARGS` 与配置 JSON；语法通过不代表参数 JSON 或导入通过。
2. 将仙工 SDK 包 `syspy.zip` 中的 Python 源文件解到副本旁的 `syspy/`，保留目录结构，忽略包中的 `.pyc`。按脚本的导入方式配置搜索路径，核对导入实际解析到的文件；混用顶层导入和带包名导入时可能需要同时加入副本根目录和 `syspy/`。按需在临时环境安装已确认的依赖；本地不改 SDK 和项目参数。
3. 检查空配置与已有配置。包内 `ParamServer` 支持 `str`、`int`、`float`、`bool`，要求 `default` 非 `None`；保留旧 `value`，可能更新默认值等元数据，未对已有 `value` 执行通用类型或范围校验。模拟器的 `@check` 则按注解检查精确类型，例如把 `int` 传给标为 `float` 的参数可触发 `TypeError`。

包内 `setDO.py` 可看任务 JSON 和一次下发；`waitDI.py` 可看跨帧查询结构，但缺失目标 DI 或超时也可能返回 `FINISHED`，不能沿用为到位判据。包内 `goPath.py` 可看路径初始化与轮询结构，带参调用与本包模拟签名有差异。运行示例前先查顶层、`__main__`、初始化及运行路径是否会写配置或连设备。模拟器多为打印、固定样例和无状态返回；例如 `setGData` 只打印、`getGData` 返回空字典，不能用它验证跨作业交接。

## 离线回放

- 从最小能区分结果的输入开始，复用真实状态机。用替身提供 RoboKit 接口、设备传输和时间。固定每一帧可见的数据及推进时刻，替身未配置的设备调用立即报错；不要在测试中真实等待或连接。
- 命令次数和设备响应各自断言。对路径或到位逻辑安排先未到位、再到位；失败分支按改动选择连接或接收超时、错配回包、缺字段、读数陈旧、未到位超时。涉及暂停、恢复、取消或重置时，断言动作是否继续、清理是否可重复、连接和阶段是否按约定处理。判断重发时分别数逻辑下发和底层发送尝试。
- 记录动作、阶段、任务标识、请求标识（如有）、时间、目标值、应答或测量值、状态及退出原因。回放输出写明注入点；在事务层注入超时只能验证上层处理，替换 socket 才能区分连接失败与写入后等不到回包。只拿真实记录做可复核的证据，替身值标成测试输入。
- 核对日志时用任务、步骤和时间窗口关联 `logInfo`、`setInfo` 上报、通信诊断和位置读数。分清当前值与目标值、原始回包与缓存。记录实际看到的最后一步和下一层缺失的证据；通信耗时和脚本终态不能代替设备反馈。

## 节拍测量

用单调时钟测量三个区间。动作耗时从步骤开始到达到约定终态，包含跨帧等待。单帧耗时从一次 `Module.run` 进入到返回。同步 I/O 耗时从调用开始到返回或异常。将三类记录按作业和步骤关联。同一帧内的 I/O 已包含在单帧耗时中。

比较优化前后的记录时，选可比的动作、配置和工况，使用相同的起止条件。说明缩短了哪一段，检查到位条件和联锁是否仍成立，并记录超时或失败。离线回放用于核对状态转换、命令次数和等待条件。实际作业节拍用目标环境的测量记录确认。

## 通用逐帧示例

示例用 Python 标准库、设备替身和假时钟。从技能目录执行 `python3 scripts/replay_action.py -v`，运行五个离线场景。见[逐帧回放脚本](../scripts/replay_action.py)。

| 场景 | 检查内容 |
| --- | --- |
| 下发、应答、到位 | 首帧只下发一次。收到应答后继续等到位，到位后结束。 |
| 缺失或错配反馈 | 缺读数、未到位及其他请求的反馈都保持等待。 |
| 超时 | 推进假时钟到截止时间，返回失败且不再轮询或重发。 |
| 设备拒绝 | 对应请求明确被拒绝，返回失败并保留原因。 |
| 取消 | 记录一次取消请求。重复取消或继续调用均不推进动作。 |

维护真实脚本时，把推进逻辑接到 `Module.run`，把取消逻辑接到 `Module.cancel`，按目标 RoboKit 的约定返回 `MoveStatus`。示例假设设备适配层已为同一请求汇总有效的应答和到位读数。实际接入时，按设备契约判断反馈的关联、时效、超时处置和取消后的状态确认。

Python 工程参考：[PEP 8](https://peps.python.org/pep-0008/) 的导入与异常处理建议；[Python 的 unittest.mock 示例](https://docs.python.org/3/library/unittest.mock-examples.html) 的替身、异常及序列返回用法。按目标版本使用语言与标准库特性。
